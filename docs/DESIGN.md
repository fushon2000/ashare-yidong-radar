# 视觉设计说明（v1.2.0）

## 为什么重做

v1.1 之前是「AI 生成审美」的典型组合：英文全大写小标题（FORWARD LOOK / WHAT-IF）、
满屏胶囊徽章、8.5px 起跳的碎字号、蓝+紫+青+琥珀多色并存、8–12px 大圆角配淡色阴影、
页面背景带径向渐变。这类界面「看起来像演示稿」，不像在用的工具。

v1.2.0 改用 **IBM Carbon 的设计语言**（开源，Apache-2.0），只借用设计规范与 token，
不引入任何运行时依赖，保持便携包「解压即用、离线可跑」。

## 落地规则

| 维度 | 规则 |
|---|---|
| 形状 | 除图表外一律方角（`border-radius: 0`），无渐变、无投影 |
| 层级 | 页面底 `#f4f4f4`，内容层 `#ffffff`，靠 1px `#e0e0e0` 发丝线分隔 |
| 字体 | 拉丁字符与数字用 **IBM Plex Sans / Mono**（本地打包），中文回退 `微软雅黑 / PingFang` |
| 数字 | 全部 `font-variant-numeric: tabular-nums`，价格与代码用 Plex Mono，保证列对齐 |
| 字号 | 11px 辅助 / 12px 标签 / 13px 正文 / 16px 区块标题 / 22px 股票名 / 28px 价格 |
| 顶栏 | 深色 `#161616`（Carbon Header 规范），其余区域保持浅色 |
| 主色 | 只有两个：交互蓝 `#0f62fe`、A股语义红 `#da1e28`（涨）/ 绿 `#24a148`（跌） |
| 控件 | 输入框为「浅灰底 + 仅留底边」的 Carbon Text Input；按钮为方角实心/描边两种 |
| 图表 | 折线不平滑、无面积填充，阈值用虚线，零轴实线 |

对照 A 股语义：**红涨绿跌**。多数开源交易终端（Bloomberg 风格）是绿涨红跌，
直接套用会产生反向歧义，因此只借鉴密度与排版，配色按 A 股重定。

## 字体授权

`src/renderer/src/assets/fonts/` 下的 IBM Plex 字体按 **SIL Open Font License 1.1**
授权分发，许可全文见同目录 `LICENSE-IBM-Plex.txt`。字体随应用打包，不联网加载。

## 兼容性

- 新增资源：4 个 woff2 文件，合计约 76 KB。
- 无新增 npm 依赖，`pnpm install` 与打包流程不变。
- 中文不依赖 Plex 覆盖：Plex 仅用于拉丁字符与数字，中文由系统字体渲染，
  因此不会出现「缺字方框」，也不需要体积巨大的中文字体子集。
